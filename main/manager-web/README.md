# xiaozhi

## Project setup

Use your code editor to import the project, and choose the `manager-web` folder as the project directory.

```bash
npm install
```

### Compile and hot-reload for development

```bash
npm run serve
```

### Compile and minify for production

```bash
npm run build
```
